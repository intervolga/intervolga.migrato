# intervolga.migrato
## 1. О модуле
Модуль миграции сущностей БД для CMS "1С-Битрикс: Управление сайтом"

Разработан для упрощения процесса слияния изменений БД с нескольких копий сайта при переносе на prod-сервер. Модуль позволяет выгрузить структуру инфоблоков, настройки свойств, групп пользователей, сайтов и т.п. в XML. Эти XML-файлы можно разместить в репозитории проекта, и на другом сервере из них восстановить структуру БД. 

Каждый проект можно сконфигурировать индивидуально и автоматически мигрировать свой набор сущностей.

## 5. Веб-интерфейс в административном разделе

После установки модуля в админке появляется раздел **Сервисы → Миграции**:

* **Команды** — список всех команд модуля с описанием и формой параметров. Вывод команды отображается в браузере в реальном времени, так же как в консоли (цвета, уровни подробности `-v`/`-vv`/`-vvv`). Команды, изменяющие данные сайта (`import`, `autofix`, `unittest` и т.п.), требуют явного подтверждения перед запуском.
* **Журнал** — таблица `intervolga_migrato_log` с фильтрами по команде, модулю, сущности, операции, внешнему коду и результату, а также выгрузкой в Excel (кнопка «Excel» в панели списка) и очисткой журнала.
* **Настройки миграции** — стандартная страница настроек модуля (`Настройки → Настройки продукта → Настройки модулей → Модуль миграций`, она же `/bitrix/admin/settings.php?mid=intervolga.migrato`). Форма читает `/local/migrato/config.xml` и собирает его заново при сохранении: список сущностей по модулям с фильтрами, правила исключения опций, настройки ORM, просмотр текущего XML и вкладка прав доступа. Сущности отключенных модулей из конфига не теряются.
* **Исходный XML** — ручное редактирование `/local/migrato/config.xml` с проверкой синтаксиса; если файла нет, его можно создать из шаблона модуля.

Доступ регулируется правами модуля (Настройки → Пользователи → Группы пользователей → Доступ):

* `[D]` — доступ закрыт;
* `[R]` — просмотр команд и журнала;
* `[W]` — запуск команд и изменение настроек.

Консольный запуск (`php run.php <команда>`) продолжает работать без изменений. Для долгих команд (`import`, `export` больших проектов) по-прежнему предпочтительна консоль: веб-запуск ограничен настройками веб-сервера на время выполнения запроса.
